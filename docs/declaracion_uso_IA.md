# Declaración del uso de IA

## Resumen

Se utilizó IA generativa como herramienta de apoyo para consultas puntuales durante el desarrollo de la actividad. Específicamente, se empleó para comprender el significado de algunos eventos de negocio y como apoyo en la sintaxis de Pandas para la imputación de datos y la generación de gráficos con Seaborn y Matplotlib. La selección de las técnicas utilizadas, el análisis de los resultados y las conclusiones presentadas fueron realizadas y validadas por el equipo.

La IA no fue utilizada para realizar el análisis estadístico, interpretar los resultados, tomar decisiones metodológicas ni elaborar las conclusiones del trabajo.
